# لوحة الرسم

تطبيق رسم Android Native مكتوب بلغة Java باستخدام Android SDK.

## الميزات
- فرشاة وممحاة، واختيار لون أساسي أو مخصص.
- حجم فرشاة قابل للتعديل.
- تراجع وإعادة.
- خلفيات متعددة، منها خلفية شفافة.
- تكبير بإصبعين.
- حفظ تلقائي عند مغادرة التطبيق.
- حفظ وفتح مشاريع محلياً.
- تصدير PNG وJPG ومشاركة PNG.

## البناء
افتح المشروع في بيئة تدعم Android Gradle Plugin 8.6.1 وJDK 17، ثم ابنِ نسخة Debug أو Release.
معرّف التطبيق الحالي: `tesiet.be.com`.

## ملاحظات
هذا مشروع مصدر أولي يحتاج اختباراً على أجهزة وإصدارات Android مختلفة قبل النشر. احفظ مفتاح توقيع Release في مكان آمن ولا ترفعه إلى GitHub.
